# HUMAN ERROR - Asset Manifest

Every third-party asset in the project, with source, creator, license and what was changed.
All runtime effects (CRT pass, photo glitch) are additionally applied by the shaders in `assets/shaders/`.

`assets/portraits/composite.jpg` (UNKNOWN INSTANCE 07 and the analyst's own record) is the per-pixel mean of the five processed portraits, with added contrast and one displaced strip.

**About the portraits.** The five sitters are anonymous people in Dutch National Archive (Nationaal Archief / Anefo) press and passport-booth photographs from the 1940s, released under CC0. They have no connection to the fictional characters. Their eyes are deliberately pixelated and displaced so that nobody is identifiable. Photographs of named individuals were intentionally not used.

## Audio

All 24 sounds in `assets/audio/` are original. They are synthesised by `tools/generate_audio.py` (Python standard library only: filtered noise, sine/square/saw oscillators, envelopes). No recordings or samples are used.

- **Creator:** generated for this project
- **License:** CC0 1.0 (public domain dedication)
- **Attribution required:** No

| File | What it is |
|---|---|
| fan.wav | Computer fan (loop) |
| crt_hum.wav | CRT electrical hum (loop) |
| fluorescent.wav | Fluorescent light buzz (loop) |
| murmur.wav | Distant office conversations (loop) |
| interference.wav | Digital interference (loop and one-shot) |
| drone.wav | Minimal music: slow detuned drone (loop) |
| key1-3.wav | Keyboard typing |
| click.wav, select.wav, open.wav | Mouse clicks and interface sounds |
| hdd.wav, boot.wav | Old hard drive seek, terminal power-on |
| notify.wav, blip.wav | Notification sounds |
| confirm.wav, deny.wav, error.wav, stamp.wav | Evidence result, error, classification stamp |
| phone_ring.wav, pickup.wav, door.wav, coffee.wav | Office objects |

Unnatural silence is produced at runtime by `AudioManager.silence()`.
